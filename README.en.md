# Bailian / Codex Quota Desktop Widget

A small always-on-top Windows desktop widget that shows **Alibaba Cloud Bailian (Model Studio) free-tier quota** for each model and **Codex quota**, and raises Windows notifications when quota is running low.

No Electron, no third-party dependencies — plain PowerShell 5.1 + WinForms, ready to run.

> Unofficial personal project. Not affiliated with, or endorsed by, Alibaba Cloud or OpenAI.

## Quick start

```powershell
git clone https://github.com/Charlie500/model-usage-widget.git
cd model-usage-widget
powershell -ExecutionPolicy Bypass -File install.ps1 -Run
```

Or copy the folder anywhere and double-click the desktop shortcut created by `install.ps1`.

### Autostart at login

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -AutoStart -Run
```

`install.ps1` generates an icon, creates a desktop shortcut ("百炼模型消耗"), optionally registers autostart, and launches the widget.

> Requires the Bailian CLI (`bl`) to be installed and logged in (`bl auth login --console`). The widget tries to re-login automatically when the console session expires; if that fails, right-click the tray icon → "重新登录百炼".

## Features

- **Bailian quota list**: 8 rows visible, sorted by remaining percentage (most urgent first). Scroll with the **mouse wheel** or **drag the slim scrollbar** to browse every model.
- **Vendor filter chips**: `All / Qwen / DeepSeek / Zhipu / Moonshot / Baidu / MiniMax / Other`; the selection is persisted.
- **Codex quota card**: shows the active Codex quota window (weekly / 5-hour), remaining %, used %, reset time and plan type.
- **7-day usage summary**: calls count and token consumption from the Bailian console.
- **Smooth dragging**: drag the title area; window position is remembered.
- **Tray menu**: show/hide (double-click), refresh, re-login, autostart, quit.
- **Notifications**: warns at ≤20% remaining, alerts at ≤8%, and notifies when quota is exhausted (Bailian and Codex alike). Notifications are throttled per target/level for 12 hours, and re-armed after recovery.
- **Hover** a row for remaining/total/expiry; **click** a row to open the Bailian console.

## Configuration (`config.json`)

| Key | Default | Description |
|---|---|---|
| `refreshMinutes` | 10 | Refresh interval in minutes |
| `types` | `["Text"]` | Bailian model types; add `Vision`, `Multimodal`, `Audio` |
| `warnPercent` | 20 | Warning threshold (remaining %, shared by Bailian and Codex) |
| `criticalPercent` | 8 | Critical threshold |
| `notifyCooldownHours` | 12 | Cooldown per target/level (hours) |
| `showRecentUsage` | true | Show 7-day calls/tokens in the summary bar |
| `autoRelogin` | true | Automatically re-login when the Bailian console session expires |
| `reloginCooldownMinutes` | 15 | Cooldown after a failed auto re-login (minutes) |
| `showCodex` | true | Show the Codex quota card |

Restart the widget after editing `config.json`.

## Data sources

| Data | Source | Notes |
|---|---|---|
| Bailian free-tier quota / 7-day usage | `bl usage summary --output json` | One call per refresh; requires a Bailian console login |
| Codex quota | `~/.codex/sessions/**/rollout-*.jsonl` | Reads the latest `rate_limits` snapshot from local session logs; **no external API calls**; only updates after Codex runs |

Codex snapshot fields used: `primary.used_percent`, `window_minutes` (10080 = weekly, 300 = 5-hour), `resets_at`, `plan_type`, `credits`.

> The Bailian console session expires periodically; the widget re-logs in automatically (silent when browser SSO is valid). If that fails, log in once from the tray menu.

## Uninstall

1. Tray menu → Quit.
2. Delete the folder.
3. Delete the desktop shortcut "百炼模型消耗".
4. Remove `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\ModelUsageWidget.lnk` if autostart was enabled.
